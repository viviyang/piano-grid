# PianoGrid Chords：从可用字典到可完成任务的V1

## 1. 结论与修正
**本轮不是N2E之后再无止境铺页。完成目标固定为：找得到 → 看得懂 → 能试听／对照弹 → 能做一次练习 → 能接到进行 → 能打印带走。**

[已核实／材料] 原规划把模板、实例、发布批次与完整范围分开；同页任务不因没有独立URL而消失。见baseline的第1、6、8节。
[已核实／用户报告] N2D v2报告为171个全站业务URL；据历次清单和RESULT对照，Chords系统为158个：145详情、7分类、6支撑页。
[推断] 当前最大的完成缺口不是“再缺多少详情”，而是大字典与仍限制在25个对象的Hub/Finder，以及有限调性/进行之间没有形成一致体验。旧批次暂不扩大范围是合理的迁移保护，不能永久当作产品完成状态。

本包纠正四件事：
1. 不再把静态200、sitemap存在、测试数量直接等同真实学习任务完成。
2. 不再把原127URL说成已全部完成。和弦扩展新增143URL，不能抵消Songs、Sheet Music等原任务缺口。
3. 不再重复创建“审阅—等待—执行—等待”的细碎批次。一次入口，按依赖连续执行，只有真实阻断才停。
4. 不再把推送当作必然不部署。后续Git和发布需要明确授权及实际分支检查。[VERCEL-GIT]

## 2. 有边界的完整产品，不是假称覆盖全部音乐
本版面向：已能找到琴键、需要查阅和理解和弦的英语自学/复学者；教师与陪练者为辅助用户。此为产品假设，未有用户分布数据。
完成承诺：在明示的和弦库内，查名称、查音符、比较结构、理解转位/排列/省略、参与网页知识练习、按调查看基础和弦、播放与练习指定进行、获取对应参考材料。
不承诺：一站替代教师、矫正手型、评估真实演奏、听音自动识别、全部爵士替代和弦、每个和弦的最佳指法、所有乐曲版权资源、无限voicing或所有拼写组合。
这些不做项是当前版本边界，不是删除长期需求。特别是“指法待核实”仍保留，不能用自动1–3–5填满。

## 3. 最终发布范围
保留现有158个Chords系统URL；本次默认只新增：
- `/chords/extended`：108个对象，9个明确子类型×12个根音，完整理论式与实际排列分开。
- `/chords/altered`：96个对象，8种明确变音组合×12个根音；`alt`只作说明，不是一组唯一音。

另补84个对象：Power fifth、Major6、Minor6、6/9、Dim7、Minor-major7、7sus4，各12个，放入已有入口，不新增详情URL。
数据共288对象，不能把288写成288新页面。

**为什么改变新增页面策略？** 原25个Add URL已经批准并实现，继续保留。N2E/F此前尚未确定具体独立详情清单。本次重新对照原规划发现，原主要缺的是Hub的power/jazz、跨家族查询与练习承接，而不是每个组合的SEO落地页。先在2个专门工具/分类页内完整交付新数据，是本次固定的产品决定，不是“2页一定比数百页排名好”。后续只有真实查询/独立交付依据再另立路由变更，不在本次自动扩页。[PLAN][G-HELPFUL][G-FACETS]

## 4. 八项用户任务验收
|任务|最终入口|必须获得|完成证据|
|---|---|---|---|
|知道名称，查琴键|Hub/所有分类/详情|支持范围内名称搜索、实际音名、图与声音|跨每个家族的查询与预览用例|
|只有音符，找可能名称|Finder|完整匹配、已定义省略匹配、多解释、低音区别|Csus2/Gsus4、C6/Am7、Caug多解释|
|看懂符号|Guide/详情/Extended/Altered|根音、质量、扩展、变化、斜杠、音级/指号/八度区别|图例＋短练习，不只是术语列表|
|比较与选择排列|详情/分类预览|理论式与实际音列；省略、重复、手别示例|当前数据一处更新，图/声/打印同步|
|练一次|Guide#practice与对象页|音类集合题、指定布局题；缺音/多音反馈|判题边界用例；非实体演奏评分|
|按调和弦|By-key|24个大调/自然小调选择，三音/七和弦表|336行逐项验证；原7调语义不变|
|把和弦连接起来|Progressions/Guide#transitions|8类练习、调性选择、速度/loop/当前和弦/打印|96份原创建议练习数据＋播放器验证|
|拿走结果|对应打印区|当前对象与实际排列；入门专题参考|生成资产与打印预览，不冒充实体打印通过|

## 5. 产品与设计的优先级
P0：输入→正确输出→可理解反馈；修复原任务真实缺口。
P1：查阅到练习与进行的上下文保留；声音/低音/拼写不混。
P2：回访便利（本地最近使用、收藏一个对象、保存练习设置），不做账号。仅复用已有储存架构；无储存权限时工具照常工作。
P3：商业化实验与高级MIDI/麦克风等，另行授权；本次不做付费墙。

## 6. 产品成功不是全部测试变绿
工程通过：包/项目自动检查、可访问页面、元信息、交互一致。
发布就绪：加上人工真机、听音、打印、具名读屏和关键音乐示例核对。
任务有效：至少做一轮真实目标用户任务观察，记录找不到入口、命名不懂、无法继续练习的地方。
SEO有效：真实GSC查询/点击/索引和用户任务数据产生后才判断，不能在代码交付时宣称成功。
后两项不能由一次Codex运行制造结果；本包已给观察脚本、指标和判断动作，不要求再写方案。
