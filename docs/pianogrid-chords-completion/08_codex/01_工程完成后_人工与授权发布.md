# 工程完成以后：不是再开发一批页

本文件不是部署授权。

1. 用户/测试者按`10_operations/manual-checklist.json`做一次真实抽检：至少一台iPhone/真实移动浏览器、耳听不同家族和省略版、真实打印、具名读屏。专业知识/指法未审仍写范围限制。
2. 用户决定提交/推送/部署前，Codex核对分支和实际Git托管自动部署关系。push可能触发部署，不能把所有push都当备份。
3. 有明确授权后按仓库既有发布流程。若仅授权commit/push，不默认授权切生产分支或切DNS。
4. 部署后核对同一次build版本：首页/Hub/Finder/By-key/进行/Extended/Altered/旧详情/资源；检查重定向、canonical、robots、sitemap、404和音频。
5. 只有线上正确版本完成上述抽检，才标记deployment_verified；不能用本地200代替。
6. 查看已有GSC/分析平台需具备权限。7/28/56天观察是建议复盘窗口，不是排名承诺或自动任务。没有数据时记录未知，不补造流量。
7. 之后只修任务阻断、实证内容缺口、明显抓取问题；不因为页面数量低于竞品就重启铺页。
