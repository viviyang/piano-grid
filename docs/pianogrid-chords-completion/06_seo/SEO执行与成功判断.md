# SEO：先让任务完整，再验证搜索结果

## 1. 已有词与新词分开
`02_routes/original-keywords.immutable.json`有191个原始保留词，来自原工作簿，保留原量/来源/归并关系。它们不是本次新研究的流量。
原P154/P158/P170经后续批准分到Minor/Major/Seventh分类，需用overlay记录主承接变化；Hub仍有实际示例和兼容锚点，不再重复大篇争同一主意图。
Extended/Altered的主词为产品意图候选，未逐词核查近期美国SERP或量。没有数据时null，不能填0或生成“高搜索量”。

## 2. 固定路由规则
保留所有已上线正确地址；只2个新增category/explorer。UI选择、音区、指法、打印、排序不增路由。
分类/详情/已有Guide用各自明确任务的title、description、H1。不开“100% all chords”“teacher-approved”等无依据承诺。
页面源码响应中须有实际标题、正文、定义、表格和href；在JSON脚本中搜到字符串不等于SSR正文通过。
过滤分享用真实可定位的章节fragment或既有UI状态协议，不称为独立搜索页面。不把canonical当无限参数crawl的唯一解决方案。[G-FACETS]
不为FAQ自动申请不适合的富结果；复用已有正确WebPage/Breadcrumb等结构数据，按可见内容写，不造评分/教师/软件价格。

## 3. 内链
Hub→所有family入口＋已有145详情紧凑目录；family→实际详情或本页真实对象锚点；详情→父family、同根相关类型、真正匹配练习；Guide→实际工具步骤；By-key/进行→上下文对应的和弦。
同页两个拼写没有各自详情时，展示其名称与键位差异，链接已存在参考但写清“same keys, different spelling”。
不得把“Practice C13”链接到不支持C13的旧练习。全库接通前由capability registry控制CTA。[G-LINKS]

## 4. 内容质量
移除错的确定性命名、修正词根小写和错误转位数量；有价值原文不删。既有重复模板若能直接给该对象音、声、打印和练习就有使用价值，但不能仅因生成数量多称权威。[G-HELPFUL]
每页先给答案，短原理，再实例与反馈；不设800/1200词、密度3%–5%指标。

## 5. 观察窗口与判断（产品建议，不是保证）
上线当日：实际canonical/indexability/sitemap/robots；核对部署SHA；代表URL真实响应；preview noindex不泄漏到production。
7天：GSC能否读取抓取/索引状态，有没有新的系统性排除。单纯暂未收录不等于页面无价值，也不当天批量改标题。
28天：按页族、国家、设备看queries/impressions/clicks/CTR；同时看真实任务完成。没曝光先排查发现/索引，再决定需求或内容问题。
56天：基于同类、相近位置与样本量，挑最高影响的3个问题修改；不要用少数曝光的CTR给整站做结论。
GSC CTR=clicks/impressions，平均位置不是每次固定排名。[G-PERFORMANCE]
本包不声称已连接或读取GSC/GA4。已有配置就复用；没有授权不能写“后台已验证”。
