# 来源使用
[已核实] 原规划来自用户上传的五份文件；当前实现来自用户各轮RESULT与相应交付清单，未访问用户C盘。
外部音乐规则参考本目录source-ledger.json。网页文本用于核对规则，未复制竞品文案、谱图、音频、PDF或课程。
[推断] 288个新对象、588个具体排列是依规则生成并经本包程序检查的原创示例，不是源作者提供的指法，也不是教师逐例审阅。
`requiredInSuppliedPlayingExample`/`allowedOmissionsForSuppliedExample` 是本包明确例子的校验契约，不是世界上所有该和弦排列都必须服从的规则。
完整理论式、实际发声集合、手别分配、指法、乐曲语境分开；不能因音高相同便把所有名称视为唯一等价，也不能因布局不同就判为错和弦。
不把旧搜索量写成新数据；新增关键词当前量一律null。
