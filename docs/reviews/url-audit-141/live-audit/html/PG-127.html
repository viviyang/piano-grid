How augmented chords are built

An augmented triad contains a root, major third and augmented fifth. The formula is 1–3–#5. Written note names remain visible even when two names share the same piano key.

Root position and inversions

Each detail page keeps the same three chord tones across root position, first inversion and second inversion. The lowest chord tone changes while the chord root and written spelling stay the same.
