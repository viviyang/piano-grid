Choose an explicit alteration

This collection covers named dominant-seventh alterations: flat or sharp ninth, flat or sharp fifth, sharp eleventh, flat thirteenth and two specific combined examples. “Alt” is not resolved to a single compulsory note set.

The accidental changes the interval

A flat or sharp in the suffix changes the named degree relative to the chord root. The resulting note is not necessarily written with the same accidental. Read the formula and written note list together.

Why ♯9 is not written as the minor third

For the C7(♯9) example, the altered ninth is written D♯ while the major third remains E. D♯ and E♭ use the same piano key in this reference tuning, but the written intervals carry different roles.

Do not omit the alteration you are studying

A reduced example may omit an unaltered fifth. It does not omit a specifically named flat fifth or sharp fifth and still claim to demonstrate that alteration. The validator checks the actual notes against the selected subtype.

Some note sets admit more than one name

A sharp-eleventh voicing with the fifth omitted can sound like an enharmonically related flat-fifth chord. The finder may return more than one explanation; neither the keyboard nor a single chord symbol establishes the entire musical context.

Compare, listen and check

Compare the ordinary dominant-seventh structure with the selected alteration. Use formula-tone and example-layout tasks separately, and keep the omissions visible in both the screen and printout.
