How the F-sharp Major chord is built

From F♯, the chord uses the root, a major third and a perfect fifth. The scale-degree formula is 1–3–5.

Root position and inversions

The same chord tones can be reordered so a different chord tone is the lowest note. The written slash symbol identifies the bass note; it does not change the chord root.

Questions about this chord

What notes are in the F-sharp Major chord?

F♯, A♯, C♯.

What is the formula for F-sharp Major?

1–3–5.

Does changing the inversion make it a different chord?

No. The chord tones remain the same; the lowest note changes.
