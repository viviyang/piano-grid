Keep the third; do not add a seventh

The added member has the pitch class of the second. The two layouts on each detail page place that member above the triad or inside it.

Read add9 and add2 with the arrangement

Open Music Theory illustrates an upper ninth and an inside-the-triad second. Musicca also lists add2 as an alternative notation. The examples show the actual registers rather than enforcing a universal label rule.

Two tasks, two kinds of feedback

Build the chord tones accepts the correct pitch classes in any octave. Match this example asks for the exact displayed pitches. An octave mismatch is not automatically a different chord.

Continue with a specific chord

Compare the major and minor added-note forms at the same root, or return to the basic triad chart. The existing Finder and progression tools retain their separately stated coverage.
