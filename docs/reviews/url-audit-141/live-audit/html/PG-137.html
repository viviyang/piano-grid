How suspended chords are built

Suspended chords replace the third: sus2 uses the second, while sus4 uses the fourth. The formulas are 1–2–5 and 1–4–5. Written note names remain visible even when two names share the same piano key.

Root position and inversions

Each detail page keeps the same three chord tones across root position, first inversion and second inversion. The lowest chord tone changes while the chord root and written spelling stay the same.
