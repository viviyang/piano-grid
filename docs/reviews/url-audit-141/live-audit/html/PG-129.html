Notes in B♭m(add9)

Use B♭, D♭, F, C. The formula is 1–♭3–5–9. Keep the D♭ third: removing it changes the note collection to a suspended shape.

The list above names the chord members. For a specific register, read the octave numbers on the selected example below.

Compare two added-note layouts

Start with B♭3 – D♭4 – F4 – C5. Then switch to B♭3 – C4 – D♭4 – F4. The C moves down one octave while the other three notes stay in place.

Both examples keep B♭ as the lowest note. This comparison changes spacing, not the bass. It is a pair of reference examples, not a complete inversion catalogue.

Questions about B♭m(add9)

Which notes make B♭m(add9)?

B♭, D♭, F, C; the formula is 1–♭3–5–9.

Does B♭m(add9) include a seventh?

No seventh is included in the complete added-note examples on this page.

Must the ninth always stay on top?

The higher-note layout is our first example, not a universal position rule. Symbols may be used differently; an exact written voicing specifies the register.

Why does a correct note set sometimes get a spacing hint?

Build the chord tones checks note names without octaves. Match this example checks the displayed pitches, so the two exercises have different targets.

Are these the only possible voicings?

No. These two examples both have the root in the bass. Other arrangements are possible but are not catalogued here.
