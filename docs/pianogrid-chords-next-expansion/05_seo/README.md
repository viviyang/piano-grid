# Keyword / TDK 使用说明

- `main_keyword` 与 secondary keywords 用于确定页面任务和语言，不代表本包重新获取了搜索量。
- `keyword_volume = null` 是刻意保留：没有把旧第三方数据冒充 2026-09-11 最新数据。
- 不增加 `meta keywords`。
- Title / H1 不要求机械完全一致，但页面对象必须一致。
- Major/Minor 分类页承接类别意图；具体和弦页承接明确对象查询，避免互相抢同一页面任务。
- F♯ / G♭、C♯ / D♭ 等等音拼写先通过正文 aliases/说明承接；没有 SERP 证据前，不批量制造重复 URL。
