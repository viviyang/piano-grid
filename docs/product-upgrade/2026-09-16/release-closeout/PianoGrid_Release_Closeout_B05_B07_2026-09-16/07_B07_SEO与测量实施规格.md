# B07｜现有页面SEO与测量收口

## 范围
只优化已有功能落地页和必要链接来源，不重做词根研究、不批量新增URL、不改品牌/主题。
核心allowlist：`/keyboard-notes`、`/keyboard-notes/labeled`、`/tools/hear-the-difference`、`/songs`、`/songs/easy`、三首现有Sheet Music版本页、`/tools`。
首页和A/C/D/E major/minor详情只校验已批准B04入口，不重做Hero或和弦正文。
确切Sheet URL用当前route registry解析；不猜slug。

## 执行顺序
1. 从当前route registry/build/sitemap形成URL基线：分别统计公开业务页、构建输出与系统页，不使用历史173/206/210相互替代。
2. 核对每页唯一任务、首屏答案、可执行主动作。已有查询/练习两模式保留，不创建同义trainer URL。
3. 清除用户可见的内部验收语言、sourceIDs与重复防御性说明。来源/访问限制保留在合适位置，不能为了简短删除版权/版本关键限制。
4. 对照关键词意图只做映射：piano notes/keys→Keyboard；labeled/print→Labeled；major-minor listening→B04；choose beginner version→Songs easy；exact sheet version→Sheet。不得标注无数据KD/volume/rank。
5. 校验title/description/H1/breadcrumb/内链文本的一致性。不采用固定800词、关键词密度或所有页套同一标题。
6. base页面自canonical；分享query状态不进sitemap，不因此宣称Google必不收录。不要新增robots block/noindex策略，除非现有事实有明确冲突另提变更依据。
7. 外部谱面资源写清访问与提供者。structured data只描述可见真实内容，不填假的评分/课程认证/托管曲谱。
8. 爬取allowlist的全部站内出链，并对全站公开路由做HTTP/sitemap smoke。hash目标要检测“存在且可见模式正确”，不是只看200。
9. 移动版可用、音频/交互资源延后不阻碍首答文本；资源404/console errors归零。性能优化仅有实测瓶颈再改，不升级依赖求快。

## 事件是否真的收集
[已核实｜历史源码，仅供线索] 旧B02/B03的keyboard-events.ts只dispatch CustomEvent并声明ANALYTICS_NOT_CONFIGURED；本次ZIP没有该文件，不能假定现已接入。
Cursor必须读最新events owner和collector。状态只能：
- `COLLECTED_VERIFIED`：已有授权provider，真实调试接收证据。
- `INSTRUMENTED_NOT_COLLECTED`：只有本地事件；不能算真实用户漏斗。
- `BLOCKED_CONFIGURATION`：需要用户账户/授权；不中断其他页面优化。
不为本批建立新用户账号、跨站跟踪、记录答案/音符输入全文或持久身份。

## 最小观测契约
| 事件类 | 表示 | 不表示 |
|---|---|---|
| practice start/completed | 本页开始/完成一轮 | 演奏技能提升 |
| hint/review | 主动用了帮助或复练 | 自动判定学习质量 |
| share intent | 打开分享面板 | 已分享成功 |
| copy completed | 写入剪贴板成功 | 发给了别人 |
| native share resolved | API resolve | 公开发布/接收者阅读 |
| valid shared landing/start | 链接恢复并开始 | 必然来自他人而非自己自测 |
| printable click/download response | 点击或资源请求 | 实体打印或课堂采用 |
| song plan step visit/self-check | 浏览/自报 | 音频自动评分 |

若已有collector支持短期匿名会话关联且满足项目同意/隐私策略，复用；否则只能报告聚合事件量/比率，不发明跨天留存与“唯一用户转化”。本地QA及自动测试事件单独标记/排除。

## 后续观测，不新增定时任务
发布后按已有真实样本查看：入口→开始→完成、错题复练、复制/接收后开始、资料使用。样本少就报原始计数与区间/限制，不用1–2个用户下转化结论。排名/索引变动和产品用法分开解释，不保证周数或月访问量。
