# 一次验收 → 授权发布 → 线上验收

## A. Cursor准备（修复完成后）
提供用户Windows可访问和iPhone可访问的同一个release candidate预览链接。localhost只对当前机器有效，不能用它完成跨设备分享验收。已有preview部署若需要远程写权限，按用户授权使用；不得擅自公开私密材料。

列出五个直接入口：Explore、合法共享preset、Labeled 61/88、B04 A pair、B04 shared pair。提供具体操作和预期，不让用户研究测试代码。

## B. 用户只完成一次实际门禁
| 项目 | 操作 | 通过条件 |
|---|---|---|
| 真机分享 | iPhone Safari打开当前共享练习/B04；分享一次、取消一次；另一设备粘贴链接 | 当前题组/pair正确，不是localhost，无答案/成绩/身份 |
| 听音和中断 | 播放/Stop，连换音；B04两段、重播、切pair、切后台回来 | 听到有效音，Stop立即生效，没有旧声音/残留播放；不是让非专业用户证明全部音高准确 |
| 练习关键流程 | 共享改黑键、Hint、Reveal、结束、复练并返回原成绩 | 每题能答；原成绩不改；可继续或退出 |
| 基础读屏 | VoiceOver或NVDA从入口到一次作答/Next/结果；打开关闭Share/退出对话框 | 名称可理解、焦点不丢、无键盘陷阱 |
| 打印 | Labeled先88后61，octaves开关；UI Print和Ctrl/Cmd+P各预览，至少一次实际输出 | 当前布局和标签一致、不缺边界键、不裁切、不多印空白页 |

任何不通过由同一Cursor按症状修复，只复验相关门禁与共享回归，不再重新设计。精确乐理/编配人工核验仅针对新音乐内容，此轮无新曲谱不得伪造“教师已审阅”。

## D. Cursor发布清单
1. 比较文件哈希；若验收后代码变了，重跑受影响测试再发布。
2. 只提交release scope以及运行它所需的依赖/数据/资源。单个文件混有无关改动时安全分离，不用`git add .`。
3. 记录release SHA、build ID、实际URL、前一个稳定deploy ID及回滚动作。
4. 线上检查Explore、hash入口、分享白/黑键、B04完整试听→揭晓、share再打开、Labeled PDF返回200与正确版。
5. 抽查首页/Tools/8个Chord内链；canonical/base sitemap与预期一致；运行时错误和资源404归零。
6. 不把线上页面可访问等同于搜索已收录。
7. 若实际事件collector未配置，写`INSTRUMENTED_NOT_COLLECTED`；已授权现有collector要证明事件到达，不含答案/身份。
8. 输出`RELEASED_VERIFIED`或`ROLLED_BACK_WITH_REASON`，然后再开启B05。
