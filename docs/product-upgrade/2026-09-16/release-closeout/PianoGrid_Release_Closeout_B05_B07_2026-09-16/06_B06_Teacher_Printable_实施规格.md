# B06｜教师可直接采用的一份资源组合

## 固定范围
[推断] 本批先制作“C4–C5 note recognition practice pack”，不是20首曲谱，也不做教师账号/班级系统。
入口沿用`/keyboard-notes/labeled#teaching-pack`；Tools只增加现有资源区的次级链接，不建`/resources/...`新SEO页。

## 交付物
一份来自同一键盘数据源的3页资源：
1. **Reference**：C4–C5键盘、清晰音名、两/三黑键定位说明；完整范围示意。
2. **Try it on paper**：相同几何但不显示音名的C4–C5键盘，8个白键填写区；不收集儿童姓名等信息。
3. **Answer key & use notes**：8个白键答案、教师使用说明、通往线上练习的可点击短链接。题目练白键时不要误说黑键也接受答案。

PDF采用已有生成/打印owner；无现成可复用生成器时，可用现有页面print/CSS路径，不为此另造音乐引擎。Letter/A4各有适配，不改变旧完整88/61参考的Letter landscape规则。QR码仅在现有工具支持时加，链接本身必须印出。

## 数据与版权边界
只用站内自有/许可键盘数据与新写教学说明；不加入外部歌曲谱面、录音或Logo。公开说明使用许可必须由项目已有license依据支持；没有依据不能擅自写“可商用/无限再分发”。

## 页面UI
`A small practice pack for your next lesson` → 范围/格式/用途 → 三页小预览 → `Download practice pack`主操作 → `Print`/`Share resource`次级 → `Try the online practice`。
共享ShareDialog、KeyboardDiagram和静态renderer；不用把HTML截图当高清谱图。
屏幕与PDF的页序、标签、答案同源；打开原生打印时清理分享对话框等UI状态，不把modal印上纸。

## 英文说明
`Use the reference page first. Then cover the labels and ask the learner to identify the white keys. Use the answer page together to check the names. The online practice is optional and does not assess piano technique.`
`Range: C4–C5. Middle C is labeled C4. This is a reference worksheet, not a full-size keyboard sticker template.`

## 外链/传播执行（不自动发信）
Cursor可准备5个相关教师/资源站的人工编辑候选：现有页面确有音乐资源推荐、来源真实、联系方式公开、资源与其读者相关。逐页查看，不按.edu或DR猜质量。
输出OUTREACH_CANDIDATES.csv（来源URL、编辑相关性、既有资源、提交方式、核查时间、推荐这份资源的理由）和5份针对页面的短邮件草稿。
不购买链接、不承诺follow、不自动注册/群发。发送需用户明确授权与可用账号。

## 验收
3页完整，PDF链接正常；Letter/A4无截断；标签/答案与layout数据一致；线上练习入口工作；用户一次实体打印；按真实下载/引用记录，不以按钮点击当成采用。
