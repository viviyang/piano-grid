# 02｜修正规格：只修差异，复用到界面与行为层

以下均为 [推断] 本轮改造决定。代码、路由与 owner 名称中的实际存在性按 Intake 复核；`KeyboardViewport`、`ShareDialog` 等是建议职责名称，不是声称仓库已有。

## 1. 全局边界

保留项目已有主题色、字体、tokens、页头/页脚、Explore/Practice tabs、已批准主体布局。不换 Hero、不生成另一套图、不批量替换 Chords/Scales。允许本包指定的局部层级、间距、状态与 Labeled 参考布局修正。

UI 控件尺寸使用现有 `--pr-control-min-size`；不要为“紧凑”缩小点击区。键盘 viewport 使用现有 `KeyboardDiagram` 与 geometry，打印复用其数据/几何和现有导出适配层，不要求打印与交互用完全相同 DOM。

## 2. 分享接收者开始页

### 固定结构

```text
Explore notes | Practice notes

Shared practice · 10 notes                      ← 一条次级信息
Find your way around the keys.                  ← 原开始标题
C4–C5 · White keys · Without labels
[ Start 10-note practice ]

[当前范围的琴键预览]
Practice options ▾
Explore with note names first →
```

- 共享提示和练习主体使用同一左边线，不再居中做第二个信息区。
- 提示内不要再放多段隐私说明或上下双分隔线；使用相邻现有 spacing token，提示到标题间距不大于 1rem（设计目标，不强制固定高度）。200% 文本允许自然换行。
- 原 `After the round` 三条说明移入 `How this practice works` 折叠说明；开始按钮优先，不再侧栏抢空间。
- 普通开始页不显示 shared 提示；过期/非法参数保留一句可恢复错误，不占整屏。
- 默认不自动开始、不发声。结束或开始新 custom round 后不残留“Shared practice”身份提示。

### 共享参数与可改选项

- `incomingPreset`：初始已验证共享配置。
- `draftConfig`：开始前用户可编辑配置。
- `activeRoundConfig`：开始时冻结，包含该轮实际 preset 与 labels 等显示规则。
- 未编辑：使用原 version/seed/option/count。
- 编辑范围或题型：设置 `isCustom=true`、移除旧 preset 强制优先级；显示 `Custom practice`；开始时创建新合法 preset。
- 题组、可点键、范围标签、提示、结果、再分享全部读 activeRoundConfig，不能各读不同的 option/state。
- v1 生成算法、题序与 query 参数不随此次修正改变。不要靠生成 v2“修复”旧链接。

## 3. 练习过程、退出与复练

```text
Question 1 of 10                          Exit practice
[progress]

Find F4
[局部键盘]
[反馈]
[ Next note ]
```

`Exit practice` 保留顶端次级文本按钮，但增加明确 hover/focus 和现有最小点击面积；不移到答题动作组。

### 退出规则

| 当前状态 | 用户动作 | 结果 |
|---|---|---|
| 开始页，无本轮记录 | 回 Explore | 直接切换 |
| 正在答题 | Exit practice | 打开一次确认；不先清状态 |
| 确认框 | Keep practicing / Esc / 关闭 | 原题、已答记录、帮助状态不变；焦点回触发器 |
| 确认框 | Discard round | 清当前轮，回 Start，不自动启动 |
| 复练中 | Back to results | 取消当前复练，保留最初完整结果、preset 和可分享题组 |
| Explore/Practice tab 切换 | 浏览另一模式 | 延续既有“保留当前轮”的行为，同时停止隐藏面板音频 |

确认文案：
- 标题：`Leave this round?`
- 正文：`Your progress in this round will be lost.`
- 主按钮/初始焦点：`Keep practicing`
- 次按钮：`Discard round`
- dialog 关联标题和说明；取消不刷新、不修改 URL、不丢原始结果。

复练不使用上述“丢弃完整轮次”handler，按钮直接 `Back to results`；原始结果与复练瞬时进度分离。

### 首答/提示/揭晓

保留三桶互斥。`Found it...added to review` 只在 assisted；independent 不入错题。标签辅助模式在结果中明示 `With labels`，不得暗示等同无标签独立识别。

首次错答：`Not quite. You chose {selectedLabel}. Try another key, or ask for a hint.`

Hint 由 pitch/geometry 支持：
- D4：`Find the white key between the pair of black keys.`
- C♯4 / D♭4：`Find the left black key in the pair of two black keys in this octave.`
- D♯4 / E♭4：右侧黑键。
- F♯4 / G♭4：三黑键组左侧。
- G♯4 / A♭4：三黑键组中间。
- A♯4 / B♭4：三黑键组右侧。

这些文案为实现夹具示例；根据实际 target、当前范围和黑键几何生成，不能对所有音高套相同句子。错八度使用已有 `scorePractice`/pitch 信息分支，避免把另一个八度说成“旁边那个键”。

## 4. 共享 ShareDialog，而不是复制按钮组

### Owner 划分

```text
业务页                         共享 UI/行为                 底层 helpers
Lookup serializer      ┐
Practice v1 serializer ├──> ShareDialog / ShareSheet ──> copyShareURL / openNativeShare
Labeled serializer     │       统一状态与焦点
B04 pair serializer    ┘
```

- 业务拥有 payload（title/text/url/context），不是让通用组件随意读 location.search 或 document.title。
- 旧 `ShareControl` 保持兼容入口，内部委托新共用 UI；不要强制所有调用方同时大改。
- 查音只保留低权重 `Copy link` 也可以，但必须使用同一复制结果/失败降级；不强推分享 modal。
- 练习结果 / Labeled / B04 按上下文提供 `Share practice` / `Share reference` / `Share comparison`，打开同一壳。
- B04 不必为文案改旧 public query。按钮可兼容现有测试名称，测试与文案同步更新且不删行为断言。

### 状态

| 状态 | 可见反馈 | 禁止 |
|---|---|---|
| idle | 简单内容说明 + Copy link + 支持时 Share | 永久空状态占大块 |
| copy成功 | `Link copied.` 紧邻主操作、礼貌播报 | 布局整体下移 |
| copy失败 | `Copy isn’t available here. Select the link below.` + 可选择只读 input/textarea | 让用户复制可能不含状态的地址栏 |
| native调用 | 禁止重复请求 | 把 resolve 记为对方收到 |
| native取消 | 安静返回，清理过期成功/失败信息 | 红色错误或“已分享” |
| native不可用/失败 | Copy link 仍可用 | 自动连发多个系统弹窗 |

`navigator.share` 从用户点击同步触发；payload/能力检查尽量在点击前备好，不先 await 无关工作消耗 activation。原生分享 UI 属系统，网页只设计外层说明与 fallback。错误提示一直保留到用户动作解决；普通 copy success 可在后续交互重置，不能让需要读屏的关键信息瞬间消失。

语义：链接不包含用户答案/分数/身份，不代表客户端题目的答案不可推算。

## 5. Labeled Piano Keys：屏幕浏览和打印拆开

页面 URL、Title/H1、标签参考职责不变，不把它改成第二个 Lookup/Trainer。

### 屏幕布局

```text
Labeled Piano Keys
Find the note names on your keyboard, then print a reference.

[88 keys: A0–C8 ▾]   [✓ Octave numbers]       [Print reference]  Download PDF  Share

[带清晰标签的共享键盘窗口：默认围绕 Middle C]
Lower notes     Showing C4–C5 / C3–C5     Higher notes
[完整 88/61 键小总览 + 当前窗口标记]

View the full reference ▾
How to label your keyboard
1. Match your layout
2. Find the repeating pattern
3. Add octave numbers when needed

Find a specific note → /keyboard-notes
Match keys to staff → /keyboard-notes/chart
Practice notes → /keyboard-notes#note-trainer
```

- 桌面控制区一条主行，必要时自然两行；Print 主操作，Download/Share 次级。所有状态消息放独立、局部状态槽，不参与按钮对齐。
- 手机第一行布局/八度设置，第二行 Print + More。More 提供 Download PDF 与 Share；不挤四个横排按钮。
- 复用 Explore 的 viewport/range calculations，default range 由布局和视口确定，不在此复制 MIDI 切片/琴键 DOM。
- label 开关仅显示/隐藏 octave 后缀，不改真实音高。
- Labeled 上“选中窗口”不是“被选中音”。不要为了标记可见范围给每个键 aria-pressed。
- 总览仅定位，不能 88 个微小点击点作为唯一操作。保留范围箭头与可访问控制。

### Full reference / 边界

- 屏幕默认不展开所有八度；用户可展开完整参考，所有 layout.keys 可查看。
- 合并边缘片段：88 键首段 `A0–B1`，中间 `C2–B2`…`C6–B6`，尾段 `C7–C8`。不要再出现 `C8–C8` 的大独立面板。
- 61 键首段起于 C2、尾段止于 C7；根据实际 layout 分组，不假定任意 61 键都同音域。
- 上述分组仅布局适配；总音数与唯一 MIDI 集合必须与真实 layout 一致。完整参考层各键只出现一次；小总览/窗口的重复展示不应被误算成数据重复。
- 既有锚点若改变分组，保留兼容目标，不能让已分享的八度锚点失效。

### Print / PDF

- 用户点击 Print：打印所选完整 88/61 范围，不只打印当前窗口，不依赖 details 当时展开。
- 打印布局继续使用现有导出 owner，只调整可读分组与分页。边界键与 octave 标注准确。
- Download PDF：先核查现有资产能否对应当前布局/标注。若 PDF 固定显示八度，则 UI 明示，不冒称“与所有屏幕选项完全一致”。无对应资产不能悄悄下载另一种布局。
- 不删除参考来源、适用范围或必要限制；去重步骤文字，不统一堆成另一本说明书。

## 6. 共享键盘的正确复用

### 现有与待提取

| 层 | 决定 |
|---|---|
| pitch / parser / spelling | 继续原 resolution/data，Hints 从真实目标读取 |
| geometry / keys | 继续 `keyGeometry` / `KeyboardDiagram`，不复制 markup |
| range viewport | 从 Explore 已有行为提取/扩展，为 Explore、Labeled 使用 |
| presentation roles | 把成熟样式从仅 `.kn-v2-*` 生效的页面选择器，收敛为显式共享外观；不污染未迁移页面 |
| practice state | 改现有 practice owner，不新造游戏框架 |
| compare state | 保留 B04 自己的业务状态，仅用相同的 keyboard presentation |
| print rendering | 与屏幕共享数据/geometry，保留现有 print/PDF adapter |

主题色不改，状态角色分离：
- focus：清晰独立轮廓，与 selected/common/source/target 不同；鼠标 hover 不伪装“选中”。
- common：相同音，浅色填充配深色标签；增加图例 `Unchanged`。
- source：原音，使用不同边界/虚线与 `Before` 标记，不用 disabled opacity 表达。
- target：新音，原主题蓝与可读前景配对，`After` 标记。
- correct/wrong/revealed：继续已批准符号与反馈，不只靠颜色。

B04 A pair 正确业务角色仅 A3/E4 common、C4 source、C♯4 target。发现 B3 边框时先判定真实 focus/hover/selected；保留必要焦点，取消无语义的残留选中。全角色可读性在白键、黑键、小尺寸和大尺寸测一遍。

普通文字 computed contrast 按 4.5:1 验收；不要以 PNG 采样冒充 CSS 合规计算。不要新增全局品牌色。

## 7. B04：保持原页面，修学习顺序与测试

- 猜前只展示两个声音、Low/Middle/High 与非剧透 key selector（A/C/D/E）；不要默认显示该 pair 的具体变化音、完整和弦音列或“third moved”。
- 教学内容使用原生 `details` 保留 SSR，默认关闭；主动打开是 `helpUsed`，用 `Comparison explained` 或 `Answer revealed`，而非无提示答对口径。
- 答后展开确切 chord names、变化音、共同音、对比键盘、相关 chord 链接；`Explore another key` 主操作，分享次级。
- 四组答案固定 middle 的设计事实不变。本轮不承诺“随机听力挑战”、不做排名或能力分数。
- B04 听完限制用音频 owner 的本轮完成状态，不靠等待固定秒数。中断、错误、Stop、换 pair 不应由旧回调重新解锁。
- 单独 Chord 1/2 试听也经过同一取消/播放 owner；不能与 comparison 重叠。
- 音频不可用允许查看解释/参考，但必须标为 with-help/revealed，不伪装听完。
- 新增 error 测试必须触发实际失败路径；注入 DOM 只能保留在单独视觉示例，不计功能 PASS。

## 8. 音频共同原则

不建立第二个 AudioContext/播放引擎。包装当前 `ReferenceAudio`，如果该 owner 已有同功能就复用。UI 明确 Play/Stop/Loading/Unavailable；重复触发只保持一个当前任务。

通过当前任务 token / cancellation handle 使旧 Promise/调度回调不更新新的 round/pair。Next/leave/换音/换 pair/hidden/unmount 等使用同一取消路径。语音提示与音高播放可共存，但不能多次播报 `Playback finished.` 干扰下一题。

## 9. 导航、SEO、测量

- 保留 B04 Tools 入口、homepage teaser、A/C/D/E 和弦内链与所有既有 URL；本次 route delta=0。
- query 仍用于状态，sitemap 仅 base。canonical 表达为“规范化声明”，不是索引保证。
- 不因为重做 UI 把参考正文改成只有客户端渲染；保留 H1、主要语义内容、来源与上下文链接。
- 目前报告显示 analytics 仅 local CustomEvent；不擅自启用追踪服务，不声称已测出复访/分享转化率。
