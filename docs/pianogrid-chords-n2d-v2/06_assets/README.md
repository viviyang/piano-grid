# 资产输入，不是已经产出的下载文件

[已核实] 本交付提供 24 组资产输入索引；本包没有 PDF/SVG 二进制。

Codex 在现有 Python/Node 资产流水线中生成。每份 reference 展示：和弦公式、两个布局各自的音名/八度/键盘、精简的 register 说明和对外可读来源。可以是一页或两页，以清晰且不裁切为准。

必须使用 adapter 已解析的相同 realization，不在生成器里再维护一套音乐定义。指定输出路径在 `asset-inputs.json`，先核对当前仓库是否已有资源，再创建/更新。

保留理论拼写，例如 D♭m(add9) 中的 F♭、A♭m(add9) 中的 C♭。标签标写法、键位按 MIDI；不是把它们静默改成 E、B。

不要声称 PDF 具有标签或读屏合规，除非实测。标签检查、实体打印和人耳测试分别报告，不用自动文件生成成功代替。
