# Codex 执行单｜PianoLab 品牌与首页 V1

## 直接任务

在现有项目中实施本包确定的品牌展示层、首页、Hero 动效与 favicon。以 `index.html` 的实际样式和行为、`design/` 的真实截图、`DESIGN.md` 的产品边界为准。

**不要再次选风格，不要将旧的几张 AI 概念图拼进这版，也不要重新规划网站。**

## 1. 先读，不覆盖

读取项目 `AGENTS.md`、Git 状态、当前设计基础、当前进度、已有验收 Notes；读取原全站规划、`url-plan.final.json`、内容总包及真实发布清单。

新设计包依次读取：`DESIGN.md` → `index.html` → `tokens.json` → `homepage-content.json` → `QA.md`。

保护现有修改；不 reset/clean；不自动 commit/push；不重装或升级依赖。继续沿用现有 Next.js、TypeScript 与 Tailwind 工程，不另起项目。

## 2. 允许变更与明确禁止

允许：统一品牌文案配置；品牌级颜色语义映射；Header/Footer；首页布局；首页专用键盘演示与大小调试听；favicon 资产；与这些变更直接相关的测试与报告。

禁止：改关键词/URL/页面任务；覆盖专业音乐内容；重写原内容包；自动开放全部规划页面；新建账号/MIDI/评分/练习记录/订阅；假评价、假曲库数量、假下载；替换整个路由系统；购买/迁移域名；部署或修改索引开放状态。

**本轮是一次新的品牌层修订。原 Foundation 的“不新增陶土色”不再约束本轮授权的品牌色，但其他产品、功能、验收与上线门槛仍然有效。**

仅同步有必要的语义 token。音符选中、根音、低音、播放中、错误、焦点不合并成同一种陶土状态；现有工具保持直接查阅的紧凑布局。

## 3. 分四步完成，不反复让用户选方向

### A. 品牌与主题

将 PianoLab 作为工作展示名，记录 `working_name_not_cleared`，不得写“商标通过”或“域名可购买”。名称来自一处站点配置。将原型中的字体回退、色值、宽度和圆角映射进现有系统；只给首页增加展示字号与品牌按钮变体。

检查桌面/手机 Header 长度；title、可访问名称、Footer 也读取一致的品牌值。

### B. 首页结构

按 HTML 的八个区域实现。复用已存在的合格组件；不要原样粘贴静态 HTML 接管整个项目。核心文本和可用内链继续服务端/静态输出；交互以小型客户端组件隔离。

主 CTA 为 Explore Piano Tools；次 CTA 为 Browse Songs。Sheet Music 通过真实发布门槛之前，不显示 Browse Sheet Music，也不把它放进 Quick Actions。

保留原 `/keyboard-notes` 等路径，不能简写成 `/keyboard` 或新造 `/practice`。

### C. 动效、声音与图标

复用原项目已有的音频引擎/键盘实现；已正确的音高与状态机优先复用。本包音频合成实现是参考，不应造成第二套冲突的全局音频引擎。

Hero 固定 A3–C4–E4，7.6 秒静音循环；提供暂停；出视区或标签页隐藏停止；减少动态时静态。点击试听与自动演示相互独立，自动循环不发声。

正文比较 A minor / A major，第三音 C / C♯，对应 `[57,60,64]` / `[57,61,64]`。避免重复点击创建无上限节点，切换/隐藏清理播放资源。不要加入手模和未经核实的指法。

使用 `assets/` 的真实 SVG/ICO/PNG；生产 favicon 使用稳定同站路径，不照抄本包 data URI。使用项目已有 metadata 机制；避免出现两个冲突的 favicon 定义。

### D. 回归并停止

先运行既有检查，再补品牌/首页专项检查。保留旧 Notes，不宣称原功能因截图好看就重新通过。

检查 320、390、768、1024、1440px：无横向溢出，标题自然换行，CTA 可见，手机三和弦完整，菜单可操作。

检查 Tab、方向键、Enter/Space、Escape、焦点恢复、减少动态、关闭 JS、音频拒绝/不可用、快速连点、离屏暂停。验证现有内页换主题后根音/低音/选中/焦点/打印没有回归。

检查所有可点击业务链接来自真实 release manifest；未发布页不得借“设计稿有入口”上线。相反，也不要拿旧文案的未就绪标记覆盖真实已验收状态。

## 4. 必须移除的原型机制

本包 `mode=standalone_design_preview`、`data-route` 弹窗拦截器、LOCAL DESIGN PREVIEW 对话框、测试用 `PianoLabPreview` 接口、Footer 的 prototype 文案，只用于独立预览。**真实网站不能保留这些业务链接拦截弹窗。**

`meta robots=noindex,nofollow` 属于独立预览的保护，集成时继续使用项目原环境化策略；本单没有取消 noindex 或开放索引的授权。

不要把 `homepage-content.json` 覆盖成原 `page-content.master.json`。新文件只描述首页展示；原事实内容与 URL 规划仍是权威。

## 5. 最终输出

输出变更文件清单、原型到组件的对应关系、主题 token 差异、实际检查命令与结果、桌面/手机截图、仍需人工检查的项。

将工作记录并入现有进度文件与评审结构，不创建互相冲突的新任务体系。

**达到本地回归完成后停止，不自签独立验收，不部署，不改 DNS，不开放索引。**

## 完成标准

可以在现有项目首页看到本版设计；琴键、试听、大小调切换、手机菜单和降级正确；原路由和内容职责不变；没有虚构功能；相关旧页面测试未回归；名称可替换但不声称核查通过。未执行的真机、听音、读屏、专业审核如实列出。
