# 本轮发现与修正

- 搜索框已有文字时，第一次Escape先触发input原生清空而非关闭dialog；现已在dialog捕获阶段明确处理Escape，关闭并返回触发按钮。
- 390px、200%根字号探测中摘要并排字段导致页面横向溢出；已增加容器尺寸驱动的纵向重排，不通过缩小字体修复。
- 无JavaScript时局部键盘方向按钮没有脚本，原本仍可见；现改为初始隐藏，仅在脚本已接入且确有滚动时开放，原生可滚动区域仍可读。
- 测试脚本曾在未来调度时间前读取AudioParam.value，得到默认值。现改为拦截实际setValueAtTime入参验证频率时间表；这不是修改音乐数据。
- 测试脚本曾将fieldset本身的Playwright可操作判断当作其子radio禁用状态。现检查实际radio的禁用状态。

最终验收是否通过，以acceptance.json为准。
