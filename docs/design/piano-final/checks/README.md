# 最终样板验收摘要

页面：`/chords/a-minor`。本轮没有部署，没有实现其他页面。

[已核实] 自动化脚本在Headless Chromium中完成197个断言，未报告失败。该数量包含不同尺寸和转位的重复测试，不是197种独立功能，也不代表已满足全部WCAG条款。

核对范围：320/360/390/768/1024/1440px布局；三个位置的符号、音序、低音与键位；实际Web Audio振荡器接收的频率与调度时间；停止、快速重播与切换；声音不可用、启动失败与等待启动取消；原生单选键盘操作、FAQ和本页搜索；PDF下载字节；打印媒体渲染与点击时位置快照；200%根字号重排探测；无JavaScript降级；输入与旧稿哈希。

[已核实] 使用HTML字节加载到浏览器进行渲染和交互，没有生成图片代替页面。运行环境阻止file://导航，故本轮使用set_content加载，未模拟你的Windows本地文件打开路径。浏览器打印PDF测试不包含真实打印对话框：测试用beforeprint事件检查点击时的数据快照，再以浏览器打印媒体渲染PDF。
