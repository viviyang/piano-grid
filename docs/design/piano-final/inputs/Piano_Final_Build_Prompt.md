# Piano Reference — 最终样板构建 Prompt

你负责将已经收敛的 Piano Reference 设计实施为一个可操作的响应式页面，不再提出新视觉方向。

## 1. 目标与范围

仅实现 `/chords/a-minor`。受众为初学到中级钢琴学习者；用户应能直接看到和弦组成音与键位，切换原位/转位，主动播放齐奏或逐音示范，停止声音，并打印当前结果或下载三个位置的参考 PDF。

以 Version A 的浅色、清晰、克制的视觉语言为唯一基础；采用 Version C 的对齐、控件分组和明确状态；采用 Version D 的阅读节奏；只借鉴 Version B 的播放操作主次及声音反馈，不引入其深色背景或绿色。

不要修改或覆盖既有 A/B/C/D 文件。使用独立的分支或原型目录保存最终版，业务 URL 仍为 `/chords/a-minor`。不扩展 `/chords` 或其他页面，不部署。

## 3. 唯一视觉系统

页面背景 #FFFFFF；工具面板 #F6F7F9；主文字 #1D1D1F；辅助文字 #5C626B；装饰分隔线 #E1E4E8；需要明显识别的控件边界 #7A828E；动作/焦点 #0066CC；选中浅底 #EAF2FF；错误文字 #B42318。

这些是本项目实施值，不是品牌官方规范。动作色与音符状态使用不同的语义变量，即使当前同属蓝色。白键保持白色、黑键保持近黑色。键位标记包含填色、圆点和音名，不依赖颜色单独表达。

使用 `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。不嵌入品牌专有字体，不把本地字体文件打包交付。H1 桌面 36/44px、手机 30/36px；章节标题 24/32px；正文桌面 17/27px、手机 16/26px；按钮 15px；关键标签至少 14px；当前音序手机至少 20px；小号辅助说明不承担关键答案。实际用 rem 实现并允许缩放。

内容最大宽度 1120px；长正文阅读宽度约 65–72ch。间距使用 4/8/12/16/24/32/48/64px。桌面工具内边距 24px、手机 16px；桌面主要章节间距 48px、手机 32px。

仅主工具区使用一个轻面板，圆角 12px、细边框、无阴影。不要再给组成音、公式、按钮、每段正文各套卡片。按钮圆角 8px；主播放按钮为蓝底白字，其余使用中性描边或清晰文字动作。

不采用整站深色、渐变、发光、玻璃效果、装饰插画、专辑封面、侧栏播放器、聊天框、仪表盘、巨大 Hero、全大写营销文案或无意义图标。

## 4. 页面结构

Header → breadcrumb + H1 + 一句直接答案 → 主工具区 → 根位示例的补充说明 → Find A, C, and E on the keyboard → A minor inversions（含比较表）→ What makes this chord minor? → Try the three positions → Print the A minor reference → FAQ → 已可用相关链接。

H1 使用内容包原文。直接答案从 am-intro 首句提取，不重新发明事实。原 intro 其余内容完整保留于根位示例说明。允许的唯一空间指代调整：呈现层将第二段中的 “The example below” 改为 “The root-position example”，避免移动段落和切换转位后产生误指；将这一处修改明确写入 content-adaptations.md，不修改原内容包。其他正文不擅自润色。

主工具区内部顺序：和弦身份与组成音 → 公式 → Position 单选组 → 当前符号、音序与低音 → 键盘图 → 播放控制 → 打印/PDF动作 → 必要说明。

组成音 A–C–E 比字段名更突出。不要让 “Am” 的大字压过真正要弹的音序。固定和弦身份与当前转位符号要分清：选择转位后可以显示 Am/C 或 Am/E，但不能把和弦根音改成 C 或 E。

导航沿用已确认栏目与实际功能。搜索只绑定现有可用搜索；如果仅是本页搜索，明确其范围。不自行创建全站搜索、假结果或空目标页。

## 5. 音乐数据与交互

所有动态结果只由一个 selectedVoicingId 派生。以下为与真实 JSON 对照的验收样例，禁止用这些样例替代读取输入：
- a-minor--root：Am；A3–C4–E4；MIDI [57,60,64]。
- a-minor--first：Am/C；C4–E4–A4；MIDI [60,64,69]。
- a-minor--second：Am/E；E4–A4–C5；MIDI [64,69,72]。

保持 C3–C5 参考范围及正确黑白键几何。SVG/DOM 根据真实数据渲染；不使用图像生成模型绘制音乐答案。音名保留原拼写；不按字符串排序；不增加未审核指法、低音、重复音、踏板或伴奏。MIDI 编号仅为内部音高标识，不是 MIDI 输入功能。

Position 在视觉上是三个分段选项，在语义上是带 legend 的原生 radio group。文案保持 Root position / First inversion / Second inversion。支持正常键盘单选操作。选择状态用底色、边界和非颜色标记表达；focus-visible 使用独立 2px 外轮廓和偏移，不能与 selected 混淆。

使用现有文案 Play chord / Play notes one at a time / Stop。按 JSON 的 playback.together / playback.ascending 使用频率、onset_ms、duration_ms，不另算一套示范。声音只由播放动作触发；切换转位、重新播放、停止、页面隐藏时取消旧声音和待执行回调，避免竞态及叠音。停止后保留当前选择和三个键位标记。

分别呈现 idle、hover、pressed、focus-visible、selected、audio loading、playing、stopped、audio error、audio unavailable、print/PDF unavailable 状态。Stop 在无播放/待启动任务时禁用；声音不可用不禁用查图、切换及已有打印功能。错误与加载文案读取 microcopy。不要给固定 Am 详情页增加根音筛选或无结果页面。

“已选中的组成键”和“正在发声的键”采用不同状态表达；当前音序始终以文字可读。状态播报简短，不逐个音符反复打断屏幕阅读器。

## 6. 手机、阅读与打印

手机按相同逻辑顺序纵向排列，允许摘要双列和按钮换行。主操作触控区域至少 44×44 CSS px，长标签不得缩成小字或省略号。Play chord 与 Stop 同排；Play notes one at a time 可独占下一排；Print 与 PDF 紧邻但不抢主按钮。

390×844 为主要检查视口：优先让当前答案、转位、键盘及主播放动作靠前，不为硬塞首屏缩小文字。另检查 320/360/768/1024/1440px。

键盘可在局部横向滚动，不能让整个页面横向溢出。设置可读的最小几何宽度（建议从 540px 调试），初始及转位切换时让当前全部标记键处于可见区域；用户能查看完整 C3–C5 范围，并有非触摸的滚动方式。横向查看必须是视口变化，不能偷偷换八度、删键或改音符。

正文不折叠成一整排开关。转位表使用真实 table/th/caption，只显示一个语义表；手机允许单元格自然换行或局部滚动，保留全部列。当前行可强调，但不把整张表再做一套选择器。

FAQ 使用原生 details/summary，问题可键盘操作、可展开多个，答案使用原文。只将 FAQ 折叠；答案、工具和转位表不能隐藏在 FAQ 内。

Print this position 只打印点击时的 selectedVoicingId；下载 PDF 包含三个位置。两种输出不混淆。打印白底深字、无导航/控件、保留音名、音区、位置名称和可灰度识别的键位圆点。不要对整页主题简单反色。用户取消打印不能被写成打印失败或成功。

先确认 PDF 文件真实存在、内容和来源；若实际文件与内容包声明不同，记录新的来源/哈希，不冒称原资产。资产缺失时显示真实不可用状态，禁止空 href、# 假下载或按钮冒充文件。

am-next 只开放已验证可用的原规划 URL。没有可用目标时保留后台映射，隐藏公开空区块；不删除规划任务，也不把设计稿中的示意链接当成已上线。

## 7. 无障碍与前端约束

以 WCAG 2.2 AA 为验收目标：普通文字至少 4.5:1，大文字至少 3:1；必要非文字状态/控件识别至少 3:1；不只依赖颜色；可见且不被遮挡的焦点；语义标题；跳至工具链接；图示替代文本；状态提示可被辅助技术获知。

本项目另规定主触控区域至少 44×44 CSS px，不要把这个项目要求说成 AA 的统一最小值。支持文字放大、320 CSS px 重排和 reduced-motion。仅真正需要二维布局的图表允许局部横向查看。实际可达性必须测试，不凭静态图宣称通过。

优先沿用现有技术栈；已有 React/TypeScript 项目就使用它，没有则交付自包含 HTML/CSS/JS。服务端/初始 HTML 提供标题、答案和基本内容；交互失败仍能读图查表。不要为一个样板新增重型动画库、音源采样、账号、订阅或后端。

可复用组件建议：PageHeader、ReferenceSummary、PositionSelector、KeyboardDiagram、PlaybackControls、PrintActions、ExplanationSection、InversionTable、FAQ、RelatedLinks。主题、内容、音乐数据、播放和打印逻辑分离；不把三音和弦字段硬套给所有音阶/指南页。
