**Title:** Piano Chord Progressions: 3 Patterns in C, E & A

**Description:** Compare I–V–vi–IV, I–vi–IV–V and I–IV–V–I in C, E and A major. Read exact four-bar examples and understand what the Roman numerals mean.

**Scope:** Three patterns in three keys: nine original four-bar realizations; not an unrestricted progression generator.

## Start with one four-bar example

Read C–G–Am–F as four chord changes. The prepared example gives each chord one bar of 4/4, with four quarter-note beats per bar. Its pattern is I–V–vi–IV in C major.

The dataset contains three patterns in C, E and A major. Each version includes a specific register and note list. These are short teaching examples, not copied song arrangements.


## Separate the pattern from its voicing

Roman numerals identify degrees relative to the selected key. They do not specify the octave, hand, inversion, rhythm or instrument sound. Those choices must be given by the individual realization.

Changing the key changes the pitches while retaining the degrees. Changing the voicing can retain the chord names while rearranging which notes are lowest. Neither operation should silently change an advertised example.


## Compare three different endings

I–V–vi–IV ends this four-bar unit on IV, making it useful for observing what happens when the sequence repeats. I–vi–IV–V finishes on V, so a following I changes the sense of arrival. I–IV–V–I includes that return in its final bar.

These descriptions tell you where the prepared unit starts and ends. They do not guarantee a happy, sad or beautiful effect. Tempo, texture, register, surrounding music and the listener can change that impression.


## Read first, then try the changes

Read one bar’s symbol and exact notes before moving to the next. When playback is implemented, the active bar, sounding pitches and displayed notes must use the same data. No sound should start merely because the page loads.

The current examples do not prescribe transition fingerings, a minimum practice speed or a fixed hand allocation. Work with the note references first rather than treating these arrays as a complete piano-performance lesson.

1. Read all four chord symbols.
2. Name one chord’s three tones without looking at its answer.
3. Compare the notes of two adjacent bars.
4. Try the change, then return to the first bar.

## Low register changes the listening example

Several preserved examples begin in octave 3. These are intentional reference registers, not a recommendation that every left-hand accompaniment should use close-position low triads.

An alternative with wider spacing or a separate bass would need its own note data and explanation. Do not label the same MIDI array as a new left-hand or jazz voicing.


## Use individual chord pages when a change is unclear

A progression should not hide uncertainty about an individual chord. Open that chord’s reference to check the third, bass or spelling, then return to the same bar of the sequence.

The reference tables remain readable without JavaScript. A transport, automatic looping or live performance feedback must not be advertised until those behaviors are actually implemented and tested.


## Questions and answers



**How many progressions are included?**

Three degree patterns, each realized in C, E and A major, for nine four-bar examples.

**Does a major-key pattern always sound happy?**

No. The pattern does not determine an emotional response on its own. Mood labels should not replace note, rhythm and context information.

**Do the Roman numerals tell me which fingers to use?**

No. They label harmonic degrees. Fingerings and hand allocation are separate decisions.
