**Title:** How to Play Piano Chords: Notes, Hands & First Changes

**Description:** Start with C, Am, F and G. Learn what chord symbols mean, separate finger numbers from note names, and compare a first C-to-Am change.

**Scope:** A guided first task, not the whole dictionary or a promise of a complete course.

## Start with one chord, not a whole song

Begin by finding C, E and G. These three different note names form the C major triad. A chord symbol is a compact instruction about a group of pitches; it does not by itself tell you the rhythm, register or best hand placement for a piece.

The reference below starts with four specific triads: C major, A minor, F major and G major. You do not need to learn every chord family before comparing these examples. Use the chart to look up another chord once this task is clear.

1. Say C, E and G aloud.
2. Locate one example of those notes on a keyboard.
3. Read the chord symbol C, then check the C-major reference.

## Read the root and quality separately

C names a major triad on C. Am names a minor triad on A. The letter supplies the root; the quality tells you which interval pattern is being used. A slash adds a bass instruction: Am/C uses A, C and E with C as the lowest sounding note.

In a formula such as 1–3–5, the numbers describe chord members measured from the root using the major-scale reference. In 1–♭3–5, the third is lowered a semitone. These are not finger numbers.


## Choose a hand example with a stated scope

Each thumb is finger 1, each middle finger is 3 and each little finger is 5. The same numbers name the same digits on both hands, not permanent keyboard positions.

The Yamaha C-major illustration supports a right-hand root-position example using 1–3–5. The current C-major detail adds its own separately sourced left-hand example. Use those examples only for the stated voicing; do not copy them onto every inversion or transition.

A left-hand bass plus a right-hand chord is a separate arrangement task. The overall bass must be taken from both hands together. A right-hand shape alone does not determine the inversion of the combined sound.


## Keep C and E: compare C with Am/C

Use C4–E4–G4, then C4–E4–A4, then return to C4–E4–G4. The two lower pitches stay fixed while the upper pitch changes. The middle chord is Am/C because C is the lowest note.

This is an original note-connection example, not an assigned fingering. There is no promise that a particular hand size should use the same fingers for both shapes. The task is to identify what changes, then try it at a manageable pace.

1. Read the first three notes and name the chord.
2. Change G4 to A4, leaving C4 and E4 unchanged.
3. Name the bass of the middle chord: C4.
4. Answer: the middle chord is Am/C, not root-position Am.

## Use the browser exercise for the right task

The existing chord builders check which pitch classes you selected. A correct result means the requested note set was selected; it does not mean your timing, hand position or acoustic playing has been assessed.

A useful sequence is to identify the notes here, try the object’s own builder, and then use the printed or on-screen reference beside your instrument. Keep those three activities distinct rather than treating a browser score as a performance grade.


## Move from a chord to a short progression

After identifying C, Am, F and G individually, read C–G–Am–F as a sequence of chord names. In C major, its scale-degree pattern is I–V–vi–IV. A progression page can then specify the meter, duration and particular voicings.

The chord chart is for lookup. This guide is for learning how to use one result. The by-key page answers a different question: which triads can be built from the notes of one selected scale?


## Questions and answers



**Do I always play chords with my right hand?**

No. Which hand plays which notes depends on the arrangement. The reference presents separate examples, not a rule that chords belong to one hand.

**Is Am/C the same as playing only C?**

No. Am/C still contains A, C and E; the slash only specifies C in the bass.

**Can I play all four starter chords with one fixed fingering?**

This guide does not prescribe that. Use the hand-specific evidence for each stated voicing rather than extending one example to every shape.
