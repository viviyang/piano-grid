## 关键词冲突与不应假装覆盖的内容

[推断] 以下是按已确认页面任务做的编辑边界，不是重新做SERP聚类：

| 相近查询 | 主承接 | 另一页如何配合 |
|---|---|---|
| piano chord chart / chart for beginners | /chords | /guide/piano-chords 解释步骤，不复制整套图表并换标题 |
| how to play chords on piano | /guide/piano-chords | 具体和弦页只讲当前对象 |
| piano fingering chart | /keyboard-notes/finger-numbers | 明示这只是数字含义；各详情提供特定原位手别案例，不宣称全能指法 |
| chords in C / key of C major | /chords/by-key 的C大调区 | /chords/c-major 是C三和弦，不吞掉整个调性查询 |
| chord finder / identify from notes | /chords/finder | 已知名称的正向查表仍在 /chords |
| B major / C-flat major | 各自拼写页面 | 等音互链，不因物理键相同就互设canonical |
| 7th、jazz、power、all chords | 保留原Hub任务台账为待补 | 19个大小三和弦不算完成这些任务，不塞进本批标题 |
