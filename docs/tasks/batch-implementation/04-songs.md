## 实现

- 使用已有真实作品条目，不照搬A minor工具排版，不增加大键盘来假装复用。
- 打开即有实际曲目和选择理由；搜索/水平/风格/情绪等筛选只根据已提供且能形成有效结果的字段开放。
- 条目应按数据展示作品/作者、具体版本或编配、适用水平与依据、难点、选择理由、真实资源入口。缺失字段不能编造，不把作品原作与某个easy编配当作同一版本。
- Easy页按原任务保留kids/adults/C-major/beautiful/impress等有材料的子任务区别；无法支持的条件留在台账，不给一排空筛选。
- 不擅自扩张到10/30/50条来满足数量词，不以通用难度标签假装已审版；不在缺等级时推算等级。
- Songs和Sheet Music里的work/edition/site-use权限分别读取；外部正规资源保持外部，不缓存谱面/音频到本站，不写成自有免费PDF。
- 已给教程/示范入口按具体版本匹配；只能外链的就准确标注，不要求用iframe绕过限制。
- 不加封面、歌单侧栏、账号收藏、AI个性推荐、会员/付费等未确认功能。
- 页内结果筛选不生成一批新SEO URL；元数据仍为两个规范路径，noindex保留。
