# 05 — 指南中心与读谱指南

先读 `MASTER-RULES.md`。本任务ID：`05-guides`。

## 范围

`/guide`（T21）、`/guide/read-sheet-music`（T22）。来源E-Guide-Reading-Practice、master具体页、资产/问题/源任务。

## 实现

- 指南中心给真实学习路径与可执行的起步例子，不能只有文章标题目录，也不把所有指南正文塞进中心。
- 读谱详情保留原文组织、谱号/音名/键位/时值/加线/记忆方法的范围及原练习答案；不能自行补充全新教材。
- 页面使用已有Foundation阅读宽度、字级、表格和例图，不重新加衬线风格；教程页不放无必要的和弦操作面板。
- SVG/谱表示例来自核对的数据/资产，不用生成式装饰图、不随意移动音符。
- 原先FACE或上下加线例子的谱号、音区条件必须保留，不改成万能规则。
- 练习可按原内容展示题目与揭示答案；不添加自动评分、成绩、账号、课程进度或承诺学习效果。
- 读谱中的查图入口连接已可用的 /keyboard-notes/chart；其他未实现指南保持后台映射，本地预览与正式发布分开。
- 原始入门/读谱PDF核对内容和适用范围再接入，不能把一张和弦图标成入门教材。

## 验收

逐block核对原英文、步骤、表格、题目和答案；图示/正文/打印对照，链接无空目标。
1440/390截图，320/768与文字放大检查；目录/锚点/折叠若实现须键盘可用，核心内容不可只藏在单个客户端状态中。
check/build，复用组件回归；输出 `checks/batches/05-guides/implementation.md`，专业审阅与程序图形核对分开记录。完成后停。
