# 07 — 首页、工具中心与首轮整合

先读 `MASTER-RULES.md` 及前00–06的实现/验收记录。本任务ID：`07-site-integration`。

## 范围

新增 `/`（T01）与 `/tools`（T02）。
整合本轮17个规划优先URL（其中A minor是已有页）。
来源F-Homepage中的对应对象及已完成页面/资源的实际状态。

如果前批尚有阻塞，仍可完成不依赖部分，但不能把这些页面写成全部可用。所有首轮条件就绪后才能报告“首轮技术验收完成”，仍不等于部署授权。

## 实现

1. 首页读取既有真实文案，以任务入口组织：选曲、找谱、琴键、和弦、音阶、指南；只让当前环境真实可用目标成为入口，不能硬造缺失页面来填满所有栏目。
2. 不做巨大营销Hero，不把整个站缩成和弦站，不宣称裸piano排名、用户数、名师背书或免费全曲谱。
3. 工具中心按动作组织现有工具/打印资料：解释能输入什么、得到什么，链接唯一规范页，不建 /tools/chords、/tools/scales 重复页。
4. 使用现有共享Header/Footer，按本轮需要完善导航，不重新设计。local preview可用性与正式发布分别维护；禁止把源published字段强行改true。
5. 相关资源、breadcrumbs、面包屑父级、打印资料入口和深链逐页联调。未实现或暂停页不会因存在JSON内容就出现可用入口。
6. 不主动新增全站搜索任务；复用既有搜索，有范围限制就准确标注。本轮需要导航不等于授权全站搜索引擎。
7. 元数据采用源标题/描述、规范路径与现有noindex配置。域名未知时不猜canonical host；不生成线上sitemap、不删除robots保护、不部署。
8. 逐条核对首轮17路由各自任务，不把模板共享当成免审核。把原91后做、19暂停和无URL任务仍留在台账，不生成占位page.tsx。

## 首轮联调

覆盖“首页→任务→参考结果→打印/资源→相关已完成页”的完整实际流程。旧功能的回归不能只靠构建成功。
检查所有首轮路由、元数据、源码内容覆盖、交互/状态、素材/外链路径、无JS基础阅读、公共文件未泄露master或问题台账。

完整跑check/build与各批测试，1440/390实际导航和工具检查；汇总对320/768等前批证据及共享修改后的重测。
新增 `checks/batches/07-site-integration/implementation.md` 和 `checks/batches/round-1-summary.md`：每页可预览状态、审查状态、剩余专业/内容/素材问题、上线前必要事项。

不将“完成17页首轮”写成“整个127页网站已完成”。等独立验收及用户后续决定；此任务到这里停止。
