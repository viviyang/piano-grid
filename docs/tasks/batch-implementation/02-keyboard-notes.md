- T05：默认有谱表—音名—琴键联动例子，支持已给谱号与范围、双向定位、主动试听、打印；不能只把谱号画成装饰图片，不能用高音谱号替代所有低音/加线任务。
- do re mi、未核实布局、上传识谱、麦克风、MIDI、电脑键盘弹奏、评分不加入。
- 新页面共享视觉系统，但不要把61/88键压进A minor两八度宽度。采用可读分段/局部滚动/定位，实际音名保持可辨。
