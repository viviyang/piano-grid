## 实现

1. 复用键盘、声音/打印基础，不把音阶塞进三和弦或转位模型。
2. 中心默认大调总览并选中C大调；根音/类型只开放该中心真实数据。详情固定当前调性，不复制全根音筛选。
3. 图、谱表、音名、构成、方向、速度、手别与范围按具体合同联动。自然/和声/旋律小调按各自提供的上/下行数组，不能用同一音序顶替全部形式。
4. 指法由手别×方向×范围×形式确定；禁止从上行倒推下行、用另一调性或另一形式套用。数据存在但专业审核条件未满足时仍遵守门槛。
5. C大调总包只转录一八度指法：没有新增证据不开放多八度指法。A minor各形式的下行指法缺项保持null，不从和弦指法填。
6. 音符已核实而某条件指法未核实时，按源合同显示音符模式并准确说明不提供该指法；缺失核心任务则标阻塞。不能删掉计划中的指法需求后宣布全量完成。
7. 只在原页面已确认的速度/方向范围内操作。方向播放与所见音序、指法对齐；停止/切换取消旧音。
8. 静态/当前/整组PDF按实际准备范围生成或接入。没有整组双手材料，不把一个C大调示例标作all/two-hand/major-and-minor全集。
